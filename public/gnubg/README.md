# Vendored GNU Backgammon core (WASM)

Source: https://github.com/ascottix/gnubg-core (v1.0.2)
Upstream engine: https://www.gnu.org/software/gnubg/

**License: GPL-3.0-or-later**

These files (`gnubg-core.js`, `gnubg-core-module.js`, `.wasm`, `.data`) are
a stripped GNU Backgammon evaluation engine for the browser. Distributing
this directory means you must comply with the GPL-3.0 terms of the upstream
project (source offer, license notices, etc.).

The rest of Backgammon Mastermind’s TypeScript game logic is separate; this
folder is the GPL-covered evaluation engine used on web builds.
