## What this branch changes

| Change | Current behavior |
| --- | --- |
| Five Inter faces, including ExtraBold | `use-app-fonts.ts` loads only those files. The splash stays up until they load, on web and native. A failed load still reveals the app. There is no `font-display: swap`. |
| iOS font names | `interFont()` uses PostScript names on iOS (`Inter-Regular`, …) and `Inter_400Regular`-style names elsewhere. `app.config.ts` embeds ExtraBold and the Android filename aliases. A **new native binary** is required before an already-installed app picks up the embedded faces. |
| Splash | The 500 ms fade is gone. The splash hides on the first layout of the ready root. |
| Off-screen play | Computer turns, helper timers, replay restore, and in-flight animations run only while the app is foregrounded and the path is `/game` (a trailing slash or `?query` still counts). |
| Sound | Warmup runs when the game screen is focused, and is skipped when sound is muted. |
| PostHog flags | `preloadFeatureFlags` is false. Nothing reads a flag. Remote config still loads, so events, screens, error reporting, and session replay stay configured. Turn preload back on in the same change that first reads a flag. |
| Timeline restore | A saved game rebuilds its undo stack in one pass when the board opens. |
| Feather icons | Imported from `@expo/vector-icons/Feather` so the full icon package is not pulled in. |

Checked on web (`localhost`, this branch) on 2026-10-01: home rendered in Inter ExtraBold/Bold with Feather icons, and vs Computer opened to the opening roll. That is not a device cold-launch measurement. Unit tests covering fonts, the activity gate, automation pause, timeline rebuild, muted sound, and session persistence passed (6 suites / 17 tests).

## Dropped from this branch

These were in the September commit or the PR description. They are not part of the change anymore.

| Item | What is true now |
| --- | --- |
| Paint the web app before Inter loads | Removed. First paint waits for the five faces. |
| Delete the Vercel toolbar script in `public/index.html` | Restored. The file matches `main`. The comments button is a Vercel preview widget, on by default. Turn it off in the project settings (**General → Vercel Toolbar → Preview → Off**) or with `VERCEL_PREVIEW_FEEDBACK_ENABLED=0`. The HTML script is only a fallback that removes the button if Vercel still injects it. See [Vercel’s comments docs](https://vercel.com/docs/comments/how-comments-work). |
| Serialize history only when history changes | Dropped in the 2026-09-15 rebase so it would not undo saved-game recovery. Persistence matches `main`: one `savePersistedSession({ state, moveLog, replayBaseline })` write. |
| September export-size table as a current result | Those numbers (web export 15.7 MB → 6.7 MB, 37 font files → 6) were measured on the old branch, before the font-wait change. They have not been re-measured. |
