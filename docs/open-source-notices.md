weights and bearoff database. The engine is used from upstream commit
[`d8325a491168062df1047ffd998f3a5dfb426a0c`](https://github.com/markbgsage/bgsage/tree/d8325a491168062df1047ffd998f3a5dfb426a0c).

is publicly available at the exact commit used by the app. This integration
does not change upstream Open Sage source files.
